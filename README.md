# DevDeploy

DevDeploy is a self-hosted developer deployment platform.

It allows developers to connect a GitHub repository, deploy applications using Docker, view deployment logs, monitor applications, and roll back failed deployments.

## Planned Architecture

- React + TypeScript frontend
- Node.js + Express + TypeScript backend
- PostgreSQL + Prisma
- Redis + BullMQ
- Docker
- Nginx
- GitHub API
- Socket.io
- Prometheus + Grafana
